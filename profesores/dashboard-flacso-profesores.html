Cómo replicar este dashboard

Instrucciones para construir tu propio dashboard de curso usando herramientas de IA, sin necesidad de saber programar.

Pasos
01
Organiza el contenido de tu curso

Reúne el programa de tu materia: semanas, temas, lecturas obligatorias, actividades y recursos. No hace falta que esté perfecto — la IA te ayuda a completar los vacíos. Un Google Doc con la estructura general es suficiente para empezar.

Google Docs
02
Sube el programa a NotebookLM

Carga tu documento en NotebookLM y pídele que genere un resumen estructurado semana a semana, con los materiales clave de cada una. Esto produce la base de datos de contenido que usarás en el siguiente paso.

NotebookLM
03
Convierte el contenido en JSON con Gemini

Pega el resumen en Gemini y usa el prompt de estructuración (ver abajo) para obtener un JSON con el listado de semanas en el mismo formato que usa este dashboard. Revisa semana por semana que los datos estén completos.

GeminiGoogle Workspace Studio
04
Genera el HTML del dashboard

En Google Workspace Studio, pasa este archivo como contexto y pídele que genere un dashboard nuevo con tu JSON de contenido. Indica el nombre de tu curso, la institución y la cantidad de semanas. El modelo produce el archivo HTML completo listo para abrir en el navegador.

Google Workspace StudioGemini
05
Personaliza colores, logo y tipografía

Edita las variables CSS al principio del archivo — todo el sistema visual está ahí. Cambia --agua por el color institucional de tu cátedra, reemplaza el logo y ajusta el nombre en el encabezado. No necesitas tocar nada más.

Editor de textoGemini
06
Publica y comparte

Sube el archivo HTML a Google Drive y usa "Publicar en la web" para obtener un link directo que abre el dashboard en el navegador, sin necesitar servidor ni cuenta de GitHub. Comparte ese link con tus estudiantes como cualquier otro recurso del curso.

Google Drive
Prompts clave
Paso 3 · Estructuración
Convertir el programa en datos JSON
Tengo el programa de mi materia [nombre] organizado en [N] semanas. A continuación te paso el contenido. Tu tarea es transformarlo en un array JSON con esta estructura exacta por semana: { num, titulo, estado, objetivo, items: [ { tipo, titulo, autor, desc, tags, estado } ] } - tipo puede ser: "lectura", "actividad" o "video" - estado puede ser: "listo", "proceso" o "pendiente" - tags son entre 2 y 4 palabras clave relevantes - autor incluye la fuente o dónde conseguir el material Devuelve solo el JSON, sin texto adicional. Aquí está el programa: [pega el contenido]
Paso 4 · Generación
Generar el HTML del dashboard
Tienes como referencia el archivo dashboard-flacso-profesores.html que te paso como contexto. Genera un dashboard nuevo para el curso "[nombre del curso]" en [institución], de [N] semanas. Usa este JSON como datos: [pega el JSON del paso anterior] Mantén exactamente la misma estructura de HTML, CSS y JavaScript del archivo de referencia. Solo cambia: - El título y subtítulo en el header - El array de semanas en el script - El color principal (--agua) por [código hex de tu color] Devuelve el archivo HTML completo.
Paso 4 bis · Iteración
Agregar o corregir contenido después de generar
En el dashboard que acabas de generar, necesito hacer los siguientes cambios en el array de semanas: [describe qué semana y qué cambiar, por ejemplo:] - Semana 3: agrega una actividad llamada "X" con la descripción "Y" - Semana 5: cambia el estado de la lectura "Z" de pendiente a listo - Semana 7: corrige el autor del video Devuelve solo el bloque JavaScript modificado (el array completo), no el HTML entero.
