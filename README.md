# IA en Educación — FLACSO × Diversa Studio

Materiales del programa de formación en inteligencia artificial para FLACSO, desarrollado por [Diversa Studio](https://diversa.studio).

## Estructura

| Carpeta | Programa |
|---|---|
| `administrativos/` | Alfabetización en IA para personal administrativo (4 semanas) |
| `profesores/` | IA aplicada a docencia e investigación (8 semanas) |
| `flacso-dashboard/` | Dashboard interactivo de materiales por semana |

## Contenidos

- **Presentaciones** por semana (PPTX) — introducción, herramientas, automatización, riesgos y ética
- **Guías de uso** de herramientas como Gemini, Claude y NotebookLM
- **Dashboard HTML** — app de una sola página para navegar lecturas, actividades y videos por semana
- **Notebooks** — demos de prompting y vibe coding en Google Colab

## Uso del dashboard

Abre `flacso-dashboard/index.html` directamente en el navegador. No requiere instalación ni servidor.
